## Lesson Structure

Each language module contains 5 lessons covering the following topics:

1. **Greetings** — Basic hellos, goodbyes, and polite expressions
2. **Numbers** — Counting, numerals, and quantity expressions
3. **Common Phrases** — Everyday expressions and conversational starters
4. **Basic Grammar** — Fundamental sentence structures and patterns
5. **Food & Vocabulary** — Food-related terms and practical vocabulary

## Vietnamese Translations

All vocabulary entries include Vietnamese translations to support Vietnamese learners throughout every language module.

## Progress Tracking

Progress is tracked per language, allowing learners to see completion status for each module independently.
