# Sentry Auto-Fix Patterns

## Pattern 1: `.at is not a function`
**Trigger:** TypeError: this.o.at is not a function
**Fix:** Add Array.prototype.at and String.prototype.at polyfill
**File:** src/main.tsx (at top)
**Test:** npm run build

## Pattern 2: `Cannot read property X of undefined`
**Trigger:** TypeError: Cannot read property 'X' of undefined
**Fix:** Add optional chaining `?.`
**File:** Where error occurs

## Pattern 3: `Failed to fetch`
**Trigger:** TypeError: Failed to fetch
**Fix:** Add retry logic (3 attempts, 1s backoff)
**File:** src/lib/api.ts
