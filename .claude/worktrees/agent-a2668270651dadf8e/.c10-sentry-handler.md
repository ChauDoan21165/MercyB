# C10 - Sentry Error Handler

## Role
Automatically fix Sentry errors as they appear.

## Error Patterns & Fixes

### Pattern 1: `at is not a function`
**Fix:** Add polyfill to src/main.tsx
\`\`\`
if (!Array.prototype.at) {
  Array.prototype.at = function(index) {
    if (index < 0) index = this.length + index;
    return this[index];
  };
}
\`\`\`

### Pattern 2: `Cannot read property 'X' of undefined`
**Fix:** Add optional chaining: `?.`

### Pattern 3: `Failed to fetch`
**Fix:** Add retry logic (3 attempts with backoff)

## Workflow
1. Receive Sentry error from user
2. Match error pattern
3. Apply fix
4. Run `npm run build`
5. Commit and push
6. Update AGENT_MEMORY.md with error + fix
7. Confirm error stops appearing

## Rules
- ALWAYS run `npm run build` before pushing
- ALWAYS add missing files to git
- NEVER push without verifying build passes
- ALWAYS update AGENT_MEMORY.md with new error patterns
