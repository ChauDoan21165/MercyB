## Template for future versions

When releasing v1.0.1, copy this file to `whats-new/v1.0.1.md` and replace the body with:

- 1 sentence summarizing the headline change
- 3–5 bullets of fixes / new features (most user-facing first)
- 1 line for any privacy / data change

Keep tone warm, no superlatives ("the best", "amazing"), no marketing puffery — Apple's review team flags it.
