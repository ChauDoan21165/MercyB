# Mercy Kids Pages Roadmap
## Version 3 — Fixed Order + Strict Anti-Duplication

---

## Purpose

One page per day. One skill per page. No duplication. No confusion.
This file is the single source of truth for all KidPages.

---

## Global Rules

1. One page = one core learning function
2. Never repeat content from previous pages
3. Each page must feel visually different
4. Each page must teach something NEW
5. Keep UI minimal
6. Keep sentences short — fit age 3–9
7. Age band tag required on every page
8. One child + one clear focus per image unless lesson requires two
9. No text inside images — visuals only
10. Character consistency within a page — same child, same style

---

## Age Band Guide

| Band | Age | What they can do |
|---|---|---|
| Tiny | 3–4 | Single words, point and say, copy sounds |
| Little | 4–6 | Short phrases, simple sentences, repeat patterns |
| Growing | 6–8 | Full sentences, I can / I am, commands |
| Stepping Up | 7–9 | Conversations, routines, stories, reading readiness |

---

## Feature Layer

| Feature | Description |
|---|---|
| Tap and repeat | Child taps image, hears word, repeats back |
| Voice recognition | Child speaks, app confirms correct sound |
| Ambient sound | Environmental audio tied to scene |
| Character continuity | Same child across related pages, outfit changes |
| Reward gesture | Pet mascot reacts on correct answer |
| Sequence mode | Images shown in order to form story or routine |
| Mirror mode | App prompts child to make the same face or pose |

---

## ⚠️ CRITICAL — Same Verb Across Pages Rule

Many verbs appear in Page 4, Page 9, and Page 10.
This is INTENTIONAL and CORRECT pedagogically.
But images MUST be visually distinct per page.

| Page | Same verb | Visual rule |
|---|---|---|
| Page 4 — Actions | jump | neutral action, plain background |
| Page 9 — I Can | I can jump | proud, successful, arms raised, slight glow |
| Page 10 — Commands | Jump! | child MID-RESPONSE, as if just heard the command |

Same verb. Different emotion. Different visual purpose.
If images look the same across pages, the system fails.
Enforce this rule in every image prompt.

---

## Build Order (follow this exactly)

### Phase 1 — Language Progression First

Build these in order. Do not skip.

```
Page 4  → Actions / Verbs         (what the body does)
Page 9  → I Can…                  (confidence + full sentence)
Page 10 → Commands                (listening + responding)
Page 11 → Feelings Expanded       (emotional vocabulary)
Page 13 → Mini Conversation       (putting it all together)
Page 14 → Daily Routine           (real life application)
```

### Phase 2 — Vocabulary Expansion

Build these after Phase 1 is complete.

```
Page 5  → Colors + Numbers
Page 6  → Animals
Page 7  → My Body
Page 8  → Family + People
Page 12 → Where? Positions
Page 15 → Opposites
Page 16 → ABC Phonics
Page 17 → Short Stories
```

**Why this order:**
Phase 1 builds language structure — verbs, sentences, commands, feelings, conversations, routines.
Phase 2 expands vocabulary — colors, animals, body, family, space, opposites, letters, stories.
Going verbs → back to nouns → back to labeling breaks the learning flow and confuses young learners.

### KidPage10 — Commands
**Status:** ⬜ Not built | **Age:** Growing | **Size:** ~60 | **Build order:** 3rd

**Goal:** Teach listening and physical response to instructions.

**Pattern:** Clap your hands! Sit down! Stand up! Jump!

**Feature:** ⭐ PRIORITY — Voice recognition + Sound detection
App speaks command → child responds physically → mic detects response → reward
Even without body detection: clap detection, voice echo, "I did it!" button
This page has highest viral potential — parents film children responding

**Character:** SAME boy — now wearing GREEN shirt, dark blue shorts.
Green = active response mode.

**Visual style for this page:**
- Child is MID-RESPONSE — as if they JUST heard the command one second ago
- Slightly surprised-then-acting expression — the "oh! okay!" face
- Body is caught in the first moment of the action, not the middle or end
- Add a subtle directional element: off-frame hand pointing, or ear tilted as if listening
- Background has a slight warm energy — soft orange or pink wash

**Word list:**
clap your hands, sit down, stand up, come here, go back,
open the book, close the door, touch your head, raise your hand,
turn around, jump up, wave hello, point to the window,
pick it up, put it down, shake your head, nod your head,
stomp your feet, touch your nose, open your mouth, close your eyes,
spin around, bend your knees, stretch your arms, take a step,
run in place, freeze, whisper, shout, tiptoe, march

**Anti-duplication rule vs Page 4:**
Page 4 clap = neutral clap, plain background
Page 10 clap = child reacting to command, slight "just heard it" expression, directional cue

**Anti-duplication rule vs Page 9:**
Page 9 = self-initiated, proud after finishing
Page 10 = responding to instruction, in the moment of starting

**Do not duplicate:**
- Page 4 neutral verb images
- Page 9 proud success images

### KidPage13 — Mini Conversation
**Status:** ⬜ Not built | **Age:** Growing + Stepping Up | **Size:** ~40 | **Build order:** 5th

**Goal:** Real two-person dialogue. Putting language together.

**Pattern:** Hello! / How are you? / I am fine. / Thank you. / Goodbye.

**Feature:** Two-voice mode — app plays both sides, child repeats one

**Character:** SAME boy — now wearing ORANGE shirt — PLUS a second character (girl, purple shirt).
Two characters per image. Social interaction focus.

**Visual style for this page:**
- TWO characters, facing each other, filling the frame together
- Clear warmth between them: eye contact, smiling, leaning slightly toward each other
- Speech shown through body language only — open hands, nodding, waving
- Soft neutral background — school corridor, park path, simple room
- Characters are equal in size — neither dominates

**Word list:**
Hello, Hi, Good morning, Good afternoon, Good night,
How are you? I am fine / happy / tired / okay / great,
Thank you, You're welcome,
Please, Sorry, Excuse me,
Bye, See you later, See you tomorrow,
What is your name? My name is ___,
How old are you? I am ___ years old,
Can I help you? Yes please / No thank you

**Do not duplicate:**
- Single-character pages
- Action or emotion focused images

### KidPage14 — Daily Routine
**Status:** ⬜ Not built | **Age:** Growing + Stepping Up | **Size:** ~80 | **Build order:** 6th

**Goal:** Real life English. Habit-building. Highest daily return rate.

**Pattern:** I wake up. I brush my teeth. I go to school. I sleep.

**Feature:** ⭐ Ambient sound effects + Sequence mode + Daily schedule reminders
Morning: birds chirping, soft light
Bathroom: running water sound
Eating: gentle kitchen sounds
Bedtime: crickets, soft wind
Parents set times → app sends gentle reminder with matching scene → child opens app at the exact right moment

**Character:** SAME boy — pajamas for morning/night scenes, school uniform for school scenes, casual clothes for home scenes.
This is the most costume-varied page — match outfit to time of day.

**Visual style for this page:**
- HOME ENVIRONMENT — warm, familiar, safe
- Time of day shown through light:
  - Morning: bright soft yellow light through window
  - Afternoon: full bright warm light
  - Evening: golden hour warm orange light
  - Night: dark blue, soft lamp light, moon visible
- Scenes are slightly richer than other pages — a hint of room context is allowed
- Still minimal — one or two props max, no cluttered rooms

**Sequence (morning → night):**
wake up, stretch in bed, open eyes, yawn,
go to bathroom, wash face, brush teeth,
get dressed, eat breakfast, drink water or milk,
pack school bag, go to school, wave goodbye to mom,
sit in class, read a book, eat lunch, play outside,
come home, change clothes, do homework,
eat dinner with family, take a bath, put on pajamas,
read a bedtime story, say goodnight, turn off light, sleep

**Anti-duplication rule vs Page 4:**
Page 4 brush = neutral action, plain background
Page 14 brush = morning bathroom context, sleepy-turning-awake expression, running water hint

**Anti-duplication rule vs Page 3:**
Page 3 = I want to sleep (desire)
Page 14 = I go to sleep (action in routine)

**Do not duplicate:**
- Page 3 wants and desires
- Page 4 neutral action style
