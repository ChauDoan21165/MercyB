## Key established workflows (carry into next session)

- **Worktree per agent off `origin/main`.** `git fetch` first; `git worktree
  list` + prune stale before claiming a branch name; staggered
  `sleep $((RANDOM%60))` before `npm ci`.
- **In-worktree `npm ci`, not symlink, when deps may change.** A stale
  symlinked shared `node_modules` produces a false "module not found" RED —
  never flag "main broken" without reproducing via clean `npm ci`.
- **Gates: `npm run typecheck:ci` (bare `tsc`) + `npm run lint` + build
  green before push.** `npm run typecheck` excludes config files; CI rejects
  what it misses.
- **RLS / schema migrations via Supabase SQL Editor, human-reviewed —
  never `supabase db push`.** No unattended catalog path exists.
- **1 PR per concern; small diffs over smart diffs; restore before
  redesign.** Money-path and central files (loaders, billing, RLS) touched
  with extra care.
- **Post-merge verification is mandatory for critical/money-path changes**
  (now Lesson 8 in For Chau Study). Compile ≠ runtime-verified.
- **Verify against current `main`, not stale audit notes** (Lesson 4). This
  doc is the canonical state-of-record for tonight.
- **Push/PR is pre-authorized only when the brief says so** (Principle #16);
  otherwise every push is a conscious act with explicit approval.
- **Agent report-prefix discipline** — each agent leads its report with its
  assigned label (e.g. "Chau — Report from B10").
