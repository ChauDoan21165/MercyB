# Mercy Kids 100-Lesson Image Roadmap
Production-ready version for image creation.

## File purpose

Use this file to create:
- lesson images
- Mercy audio lines
- child reply targets

## Global image rules

All images should be:
- bright
- simple
- calm
- easy to understand in 1 second
- toddler-friendly
- not crowded
- centered on one clear object, action, or tiny situation
- no text inside image
- no complex background
- no realistic photo style

## Global prompt style

Use this visual style unless a lesson needs a small scene:
- cute preschool educational illustration
- soft bright colors
- clean edges
- rounded friendly shapes
- simple clear composition
- one main focus
- white or very light soft background
- high readability for ages 3–7

## Lesson template

Each lesson below includes:
- **Image filename**
- **Image brief**
- **Image prompt**
- **Mercy audio**
- **Child target**
