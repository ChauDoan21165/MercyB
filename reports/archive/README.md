# reports/archive — historical docs

Work logs and reports from the **pre-pivot "Mercy Mind Link / wellness-VIP" era**
(Oct 2025 – Jan 2026) and superseded reference docs. MercyBlade is now a Vietnamese
English-learning app with **no VIP tier**; these describe a product/architecture that no
longer matches reality. Kept for historical record only — **do not treat as current**.
Source of truth for current state: `CLAUDE.md`, `ROOM_GUIDE.md`, `SECURITY.md`,
`PRINCIPLES.md`, and (strategy) the `strategy-docs-update` workstream.

Archived 2026-05-17 by the `docs-consolidate` workstream (RECON-docs-consolidate.md).
History preserved via `git mv`.
