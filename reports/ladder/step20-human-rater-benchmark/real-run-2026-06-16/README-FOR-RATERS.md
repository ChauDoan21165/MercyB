# Step 20 Human-Rater Benchmark

Please review each learner example and Mercy's tutor/app output.

For each row, score 1–5:

- 5 = excellent
- 4 = good
- 3 = acceptable but weak
- 2 = partly wrong
- 1 = wrong, unsafe, misleading, or harmful

Judge these dimensions:

1. Correction accuracy
2. Explanation quality
3. Learner safety and kindness
4. Vietnamese L1 relevance
5. Pedagogical next step
6. Evidence grounding

Mark `critical_failure_yes_no = yes` if the tutor:
- invents facts
- gives unsafe advice
- corrects when it should ask clarification
- is rude or discouraging
- gives unsupported certainty
- teaches something wrong

Score only what is visible. Do not guess hidden intent.
