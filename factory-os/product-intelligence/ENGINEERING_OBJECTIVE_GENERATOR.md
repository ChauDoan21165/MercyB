# Engineering Objective Generator

Converts one objective-ready EngineeringInvestment into one bounded EngineeringObjective.

Boundary:
- Factory OS only.
- No runtime readiness claim.
- No product capability verified claim.
- No implementation before ECON.
- One objective at a time.

Required EO fields:
- PCAP
- PFLOW
- problem
- product value
- allowed files
- forbidden files
- acceptance criteria
- verification commands
- anti-fake checks
